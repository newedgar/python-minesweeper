**Minesweeper Game in Python**

This project is a Python Minesweeper game with a Tkinter GUI.

## How to run

Launch the game from the main entry point:

```bash
python minesweeper.py
```

## Project structure

- `minesweeper.py`: main entry point and game logic (`Board`)
- `gui.py`: main menu and board GUI

## Features

- Main menu with board size selector
- Start button to launch a game
- Secondary placeholder button for a future mode
- Interactive board with click to reveal and right click to flag
- Colored revealed numbers
- Bombs shown with an emoji
